## 📖 Tentang Repositori

Repositori ini merupakan dokumentasi perjalanan belajar pengembangan web *front-end* (**HTML** & **CSS**) mengikuti alur kurikulum **WPU Course (Web Programming UNPAS)**. Berisi kumpulan kode latihan bertahap mulai dari struktur dasar HTML, manajemen *version control* dengan Git & GitHub, elemen semantik, pembuatan tabel dan formulir, hingga pengerjaan studi kasus halaman web.
